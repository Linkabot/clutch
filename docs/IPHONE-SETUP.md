# iPhone Setup

How to install Clutch on an iPhone as a home-screen app.

## Install

Open `<PAGES_URL>` in Safari, tap Share, tap "Add to Home Screen", then tap
Add.

## What to expect

The app opens full-screen with no address bar. The Me tab shows "Offline
ready" once the service worker has finished caching.

## Test offline

Turn on Airplane Mode, then reopen the app from its Home Screen icon.

## Updates

Updates apply automatically the next time the app launches with a network
connection.

## Troubleshooting

Remove the icon from the Home Screen and re-add it, or clear Safari's
history and website data via Settings → Safari → Clear History and Website
Data, then reinstall.
