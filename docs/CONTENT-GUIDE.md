# Content Guide

Skeleton only — Phase 1 adds the actual schemas, scripts and content.

## Principles

Content is data, not code: JSON + Markdown under `content/uk/`, validated
against Zod schemas in `src/content/schemas/`. `npm run validate:content`
must exit 0 and runs inside `npm test`. Phase 1 adds the schemas and the
script; Phase 0 only reserves the names.

## Schemas

Zod schemas live under `src/content/schemas/`, one file per content type,
re-exported from `index.ts`:

- `pack.ts` — `PackSchema`, for `pack.json`.
- `highwayCode.ts` — `RuleSchema`, `SectionSchema` and
  `HighwayCodeIndexSchema`, for `content/uk/highway-code/`.
- `facts.ts` — `FactSchema` and `FactsFileSchema`, for `facts.json`.
- `syllabus.ts` — `SyllabusSchema`, for `content/uk/syllabus.json`.

`content/uk/highway-code/` and `content/uk/syllabus.json` are generated by
the ingestion scripts (`scripts/ingest-highway-code.ts`,
`scripts/ingest-national-standard.ts`) and are never hand-edited.

## Pack

`pack.json` = `{ region: "GB", version, attribution[] }`.

## Facts

`facts.json` is the ONLY permitted source of numbers in questions. Each
fact cites its Highway Code rule or gov.uk source.

Every fact carries a `verification.method`, one of:

- `quote-in-rule` — the fact's `quote` is a verbatim substring of the
  cited rule's (or section's) ingested text.
- `pending-human` — a number copied from an official source that still
  needs a human check against the original chart or page
  (`verification.against`).
- `human-vs-official-chart` — a `pending-human` fact a human has since
  confirmed against the official chart, recording who (`by`) and when
  (`on`).

`quote` must be a verbatim substring of the cited rule's ingested text —
never paraphrased and never typed from memory. It is copied from the
committed section JSON: `htmlToText` of the cited rule's `html`, or of the
cited annex's `bodyHtml`. When a fact's `value` is a number, the quote
must also name that value itself (the digit, or an accepted word form
such as "two" or "doubled") — a table row's label alone is not enough. A
number that cannot meet this is dropped, never adjusted to fit.

Seeded fact ids (Step 11 — Rules 124, 126, 226, 100 and Annex 6):
`speed-limit-built-up-default`, `speed-limit-built-up-wales`,
`speed-limit-cars-single-carriageway`, `speed-limit-cars-dual-carriageway`,
`speed-limit-cars-motorway`, `following-gap-seconds`,
`following-gap-wet-multiplier`, `following-gap-icy-multiplier`,
`tunnel-stop-gap-metres`, `fog-visibility-headlights-metres`,
`child-restraint-height-metres`, `seat-belt-child-age`,
`tyre-tread-minimum-mm`. Stopping-distance facts (Step 12) are seeded
separately and stay `pending-human` until a human confirms them against
the official chart (Step 13).

## Questions

Field list: `id`, `category` (one of the 14 DVSA topics), `stem`,
`options[]` with exactly one correct, `explanation`, `refs[]` that must
resolve, `tags[]`, `difficulty`, optional `syllabus[]`, optional `image`.

## Signs

Field list: `id`, `name`, `family`, `shape`, `colours`, `meaning`, `hook`,
`image` (file must exist), `refs[]`, `licence`, `source`.

## Attribution

`public/ATTRIBUTION.md` is shipped and shown on Me. Highway Code text carries "Contains public sector information licensed under the Open Government Licence v3.0."

## Never

No pasting from commercial sources. No video fetching. Links out only as
clearly online-only extras.

## Regional differences

State regional differences explicitly rather than averaging them — for
example the Scotland drink-drive limit and the Wales 20 mph default.
