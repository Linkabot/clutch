Write theory-revision questions for a UK learner driver, using only the unit text given below.

Rules:

- Use plain English a learner can follow.
- Give four options for a multiple-choice question, or two options for a true/false question.
- When the answer is a phrase drawn from the unit text, every wrong option needs a `keyPhrase`
  that is a verbatim substring of that option's own text.
- When the answer is a value (a number, a distance, a speed), leave every option's `keyPhrase`
  null.
- Never invent a fact, a number or a rule that is not in the unit text or the facts given below.
- Never describe or reference a picture; no option may depend on seeing an image.
