Write a short revision lesson for a UK learner driver, using only the unit text given below.

Rules:

- Use plain English a learner can follow.
- Each rule card names one rule or unit, quotes it verbatim, and gives a one-line plain-English
  summary of it.
- A check card's question follows the same rules as a stand-alone question: four options, or two
  for a true/false question, and the same `keyPhrase` rules as below.
- When a question's answer is a phrase drawn from the unit text, every wrong option needs a
  `keyPhrase` that is a verbatim substring of that option's own text; when the answer is a value,
  leave every option's `keyPhrase` null.
- Never invent a fact, a number or a rule that is not in the unit text or the facts given below.
- Never describe or reference a picture; no option may depend on seeing an image.
